# 🌍 Travel Project

A simple React application that displays a list of travel destinations using reusable components.

This project was built with **React + Vite** as part of my learning journey to practice component structure, props, and list rendering.

---

## 🚀 Features

- Display travel destinations as cards
- Reusable React components
- Data-driven UI (using a JSON dataset)
- Conditional rendering (e.g. labels like “All Inclusive”)
- Responsive layout (basic)

---

## 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES6+)
- CSS
